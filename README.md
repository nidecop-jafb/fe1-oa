# fe1-oa

Site dos estudantes de **Fisica Experimental 1** — IFMG campus Ouro Preto.

Publicado por `publicar_trilha_fe.py` (FE1/_scripts). Nao editar os arquivos
de `t*/` a mao: eles sao copias geradas a partir dos OAs canonicos da trilha.
A apresentacao do topo e o rodape do `index.html` sao escritos a mao e ficam
entre as ancoras `<!-- TRILHAS:INICIO -->` e `<!-- TRILHAS:FIM -->`.
